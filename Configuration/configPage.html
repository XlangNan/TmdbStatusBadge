TMDB 完结状态角标 - 设置

→ 打开"剧集状态管理"（手动设置某部剧的完结/更新中状态）
在 themoviedb.org 账号设置 -> API 里申请，免费。
关闭（默认）：状态变化只是轻量通知 Emby"图片变了"，大多数情况下网格列表/详情页会跟着实时刷新。
打开：会真正触发一次"刷新元数据 + 替换图片"，Emby 自己各种尺寸的缓存图都会重新生成， 效果最彻底，但会重新请求你配置的元数据源，比较吃资源，剧多的话不建议开。
默认 26，数值越大角标越大。素材会按这个比例等比缩放。

自定义角标图片（可选）

不上传就用插件自带的丝带样式。上传自己的图后，插件会直接把整张图 按"角标宽度占海报宽度的百分比"缩放贴到你选的那个角落——注意自己的图 如果本身是斜着带方向的，插件不会帮你转方向，四个角落贴的都是原图， 建议上传本身就不带方向性的图案（比如一个圆形印章、一个图标）最省心。 建议图片体积不要太大（几百KB以内），过大的图会让配置文件变得很臃肿。
